# Student Expense Tracker

A beginner-friendly console-based expense tracker developed using C programming.

## Features
- Add new expenses
- View all expenses
- Calculate total expenses
- Save expenses using file handling
- Load previously saved expenses

## Concepts Used
- Variables and data types
- Arrays
- Loops
- Switch statements
- File handling

## Technology Used
- C Programming Language
- Online C Compiler

## How to Run
1. Open `main.c` in a C compiler.
2. Compile the program.
3. Run the program and select an option from the menu.
