# Student Expense Tracker

## About the Project
The Student Expense Tracker is a beginner-friendly console-based application developed using C programming.

It helps students record, view, and calculate their expenses.

## Features
- Add new expenses
- Store multiple expenses
- View all expenses
- Calculate total expenses
- Save expenses using file handling
- Load previously saved expenses

## Concepts Used
- C programming
- Variables and data types
- Arrays
- Loops
- Switch statements
- Functions (planned improvement)
- File handling

## Technology
- Programming Language: C
- Compiler: Online C Compiler

## How to Run
1. Copy the source code from `main.c`.
2. Open a C compiler.
3. Compile and run the program.

## Project Status
Completed beginner-level version. Further improvements are planned.
